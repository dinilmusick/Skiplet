# Exposition

Numbered chapter Markdown files are the canonical page source for this exhibition. Files such as `01-opening.md` with a matching first heading `# 01 — Opening` become carousel pages in number order. This optional index is not a page.

After adding, removing, renaming, or renumbering a chapter, run `skiplet generate pages` (or `npm run generate:pages`). Do not edit `src/generated/pages.json` manually.
